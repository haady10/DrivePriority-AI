# DrivePriority-AI
Early failure warning and risk-based maintenance prioritization for cloud storage infrastructure.

## Master cleaning distribution 0.3.0

The code-only Windows cleaning package supports five recognized operators, append-only
leader authorization, three-level source evidence, immutable anomaly analysis, and
version-aware revalidation of compatible v0.1.4 outputs. It does not require Git.

Start with `docs/C1_TEAM_README.md`, then run `RUN_ME.cmd help`. Raw archives,
cleaned Parquet data, approval records, and credentials are intentionally excluded.
